v22는 원본 핀볼의 화면 배치를 복원한 버전입니다.

복원:
- 기존 관리자 화면 레이아웃 그대로
- 기존 왼쪽 참가자 입력/목록 영역 그대로
- 기존 상단 화면 선택/공용·야미·꿀혜·선하·도릿 구조를 건드리지 않음
- 개인핀볼/단체핀볼 등 기존 원본에 있던 UI는 원본 그대로 유지 (새로 만든 불필요 UI 추가 없음)

내부만 변경:
- Render Node 서버
- 각 방 독립 상태
- 누구나 조작 가능
- 각 브라우저 로컬 물리
- 리더 체크포인트 동기화
- 새로고침/중간접속 복구
- 대용량 공 최적화

배포: 프로젝트 전체 교체 후 GitHub Commit/Push → Render 재배포.
