확실한 5초 대기 + 시작자 렉 완화

1. 시작 시간
- 서버 startedAt = 버튼 클릭 처리 시점 + 5000ms 유지.
- 클라이언트 begin()에 절대 시작 게이트 추가.
- setTimeout이 일찍 깨거나 서버시계 보정값이 중간에 달라져도 startedAt 이전이면 startPhysics()를 절대 호출하지 않음.
- 시작 버튼 직후 '5초 뒤 모든 화면 동시 출발 준비!' 안내.
- 즉, 시작한 컴퓨터도 서버 공통 시작시각 전에는 공이 떨어질 수 없음.

2. 시작자 렉 / 팝업 반응
- 직전 맵 이탈방지에서 Wheel 외곽선을 공마다 매 프레임 전체 polyline 검색하던 부분이 CPU 부담이 컸음.
- Wheel 외곽선 segment를 한 번만 미리 만들고 y값 0.1 단위 결과를 캐시.
- 대부분의 중앙 공은 정밀 경계검사를 건너뛰고, 실제 외곽 근처 공만 검사.
- 공 수가 많은 경우 snapshot 포장/전송 빈도를 조금 낮춰 시작자 메인스레드 부담 완화.
- 물리/당첨/팝업 로직 자체는 변경하지 않음.

3. 맵 이탈 방지
- 기존 기능 유지.
- 실제 선 밖으로 나가려는 공만 안쪽으로 복귀.
