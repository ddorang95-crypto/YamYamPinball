얌얌랜드 핀볼 v17.11.3 - 전 화면 동기화 / 결정론 물리 최소패치

기준
- 사용자가 올린 정상 작동 v17.11.1을 기준으로 함.
- HTML/CSS/기존 UI/맵/참가자 입력/당첨팝업/방 구조/Render 설정은 수정하지 않음.
- 수정 파일: app.js, server.js

1. 모든 조작 상태 동기화
- 당첨 기준 변경 → 같은 방 모든 화면에 즉시 반영
- 경기 초기화 → 같은 방 모든 화면이 즉시 로비 상태로 돌아감
- 맵/참가자/설정 변경 → 서버 상태를 기준으로 다른 화면에도 반영
- 기존 로컬 레이스가 서버 상태를 강제로 덮어쓰던 코드를 제거
- 새로고침 → 서버의 현재 방 상태를 다시 읽어 동일 상태로 복귀

2. 같은 레이스 화면
- 시작한 화면이 먼저 출발하지 않음
- 서버가 raceId + seed + 공통 시작시각을 먼저 확정
- 같은 방 모든 화면이 같은 시작시각에 각자 로컬 물리를 시작
- 진행 중 다른 화면의 snapshot 좌표를 계속 덮어쓰지 않음
  → '잠깐 멈춤 → 갑자기 따라잡기' 렉 제거

3. 내려가는 순서/속도 일치 강화
- 기존 Math.random 기반 런타임 물리 랜덤을 race seed 기반 결정론 RNG로 교체
- 각 화면의 FPS 누적시간으로 물리를 돌리지 않고 서버 공통시간 기준 8.333ms 고정 tick 사용
- 같은 seed + 같은 tick + 같은 RNG 순서를 사용해 공의 속도/충돌/순서를 최대한 동일하게 유지
- 카메라도 로컬 물리 상태를 기준으로 동일 계산
- 공식 finish/result는 시작한 화면 하나만 서버에 기록하여 중복 결과 방지

4. 새로고침/중간접속
- 이미 진행 중인 레이스에 새로고침/중간접속하면 최신 snapshot을 최초 1회만 적용해 현재 위치에 합류
- 합류 후에는 snapshot을 계속 따라가지 않고 다시 로컬 물리로 진행
- 따라서 복구는 되면서 평상시 보정 끊김은 없음
