정상 작동 v17.6 최소 수정판

HTML/CSS/UI 파일은 원본과 100% 동일하게 유지했습니다.
수정한 파일은 app.js, server.js뿐입니다.

수정:
- 시작 버튼을 누르면 서버가 raceId/seed/공통 시작시각을 먼저 확정.
- 같은 방의 모든 화면이 같은 시각에 자기 브라우저에서 같은 seed로 레이스 시작.
- 레이스 진행 중인 화면은 다른 화면의 snapshot 좌표를 계속 덮어쓰지 않음.
  → 멈췄다가 갑자기 다른 화면을 따라가는 현상 제거.
- 기존 클릭 동기화 / 방 구조 / 맵 / 카메라 / UI / Render 배포 방식은 그대로.
- 물리엔진, 충돌, 공 개수 제한도 이번 최소 패치에서는 건드리지 않음.
