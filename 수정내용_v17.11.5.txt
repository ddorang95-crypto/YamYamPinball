v17.11.5 공식 공유 타임라인

- 모든 화면이 같은 공식 snapshot 스트림을 봄.
- 물리는 host 한 곳만 계산하지만 host 자신도 실시간 로컬 화면을 직접 보지 않고 서버에서 다시 받은 공식 스트림을 봄.
- 서버가 각 snapshot에 서버 수신시각을 기록.
- 모든 화면은 서버시각 기준 약 420ms 지연된 동일 프레임을 60fps 보간 재생.
- 공 도착 순위는 서버가 약 650ms 미래의 표시 시각(at)을 예약.
- 당첨 팝업은 약 700ms 미래의 표시 시각(at)을 예약.
- 데이터가 먼저 도착해도 표시 시각 전에는 순위/팝업을 보여주지 않음.
- 서버/브라우저 시간차는 RTT midpoint 방식으로 계속 보정.
- 새 레이스/초기화 시 이전 예약 이벤트 타이머 삭제.

정확도:
인터넷/OS/브라우저/모니터 주사율 때문에 수학적으로 0.000초 완전 동일을 보장할 수는 없음.
대신 즉시성보다 동기화를 우선해 공통 지연 버퍼와 서버 예약시각을 사용하며 정상 네트워크에서 0.1초 이내 체감 동시성을 목표로 설계.
