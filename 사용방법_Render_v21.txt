얌얌랜드 핀볼 v21 - Render 공용 5방 / 전원 조작

기존처럼 Render 사이트에 배포해서 사용합니다. PC에서 START.cmd를 켤 필요 없습니다.

첫 화면:
/  → 공용 / 야미 / 꿀혜 / 선하 / 도릿 선택

각 방:
COMMON / YAMI / KKULHYE / SUNHA / DORIT
각 방의 참가자, 레이스, 정지, 결과는 서로 독립적입니다.

누구나 room.html에서:
- 공 추가/삭제/수량 조정
- 맵/당첨기준 설정
- 레이스 시작
- 일시정지/계속
- 초기화
를 할 수 있습니다.

동기화:
- 시작한 브라우저가 그 레이스의 리더가 됩니다.
- 다른 화면도 같은 raceId/seed로 자기 브라우저에서 로컬 물리를 돌립니다.
- 리더는 저주기 체크포인트만 서버에 올립니다.
- 새로고침/중간접속 화면은 체크포인트로 현재 진행상태를 따라붙습니다.
- 시작한 사람이 새로고침해도 sessionStorage clientId가 유지되어 같은 리더로 복귀합니다.
- 리더가 완전히 사라지면 약 5.5초 뒤 다른 접속 화면이 자동으로 리더를 이어받습니다.

대용량:
v20의 대용량 최적화(공이 많을 때 공-공 충돌 완화, 렌더 해상도 자동조절, 체크포인트 주기 완화)를 유지합니다.
'무한' 물리 객체는 브라우저/PC 한계상 불가능하지만 기존 1000공 부근 급격한 렉을 줄이는 방향입니다.

Render:
Build Command: npm install
Start Command: npm start
PORT는 Render 환경변수를 자동 사용합니다.
기존 yamyampinball Render 서비스의 저장소 파일을 이 버전으로 교체해 재배포하면 기존 onrender.com 주소를 유지할 수 있습니다.
