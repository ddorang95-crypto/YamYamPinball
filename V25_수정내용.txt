v25 핵심

화면
- 첫 접속부터 기존 핀볼 본화면.
- 상단 헤더 중앙에 공용 / 야미 / 꿀혜 / 선하 / 도릿 방 선택이 항상 표시.
- 기본 방은 YAMYAM이 아니라 COMMON(공용).
- 개인 핀볼 / 단체 핀볼 버튼 제거.
- 레이스 시작 옆에 일시정지/계속 버튼 추가.
- 기존 참가자 입력/목록/맵/당첨기준 UI 유지.

실시간 동기화
- 0.18초마다 남 화면을 따라가는 방식 대신 SSE 실시간 이벤트 연결 추가.
- 누군가 공 추가/삭제/시작/정지/초기화를 누르면 서버가 그 방의 모든 브라우저에 즉시 상태 이벤트 전송.
- 레이스 시작은 서버가 약 1.8초 뒤의 하나의 공통 시작시각을 확정.
- 각 화면은 같은 raceId + seed + 공통 시작시각으로 자기 브라우저에서 동시에 물리를 실행.

렉/화면 일치
- 진행 중 다른 화면 좌표를 계속 덮어쓰는 보정은 하지 않음.
- 서버 공통 시간 기준의 고정 8.333ms 물리 tick 번호를 사용.
- FPS가 조금 달라도 모든 화면이 같은 목표 tick을 따라가므로 기존 프레임 누적 방식보다 화면 차이가 훨씬 적음.
- 중간 접속/오래 지난 뒤 새로고침한 경우에만 체크포인트 1회 사용.
- 평상시 진행에는 체크포인트 따라가기 때문에 생기는 뚝뚝 끊김이 없음.
- 일시정지/재개/초기화는 SSE로 즉시 전체 화면에 전달.

주의
- 수천 개 실제 Box2D 공은 각 PC 성능 차이가 있으므로 물리 계산 자체의 절대 '무한'은 불가능.
- v25는 대용량일수록 한 프레임 catch-up 연산을 제한해 브라우저가 통째로 멈추는 현상을 줄임.
