즉시 낙하 + 시작자 렉 수정

1) 시작 누르자마자 공이 떨어지는 현상
- 서버 공통 시작시각을 요청 처리 시점 +6초로 설정.
  (다른 PC까지 시작 이벤트가 늦게 전달되는 환경을 고려한 여유)
- 시작한 PC에는 별도로 performance.now() 기준 최소 5초 하드 게이트 추가.
- 서버시계 보정이 순간 흔들리거나 타이머가 일찍 깨도 500ms 간격으로 남은 시간을 재검사.
- 서버 공통시각과 로컬 최소 5초를 둘 다 통과하기 전에는 startPhysics() 절대 실행 안 됨.
- 화면 메시지에 '레이스 N초 뒤 동시 출발 준비' 카운트다운 표시.
- apiQuiet에서 이미 RTT 보정한 serverNow를 start 버튼에서 다시 stale 값으로 보정하던 중복 syncNoteClock 호출 제거.

2) 시작한 사람 화면 렉 / 당첨팝업 지연
- 기존에는 공이 결승에 들어올 때마다 finishBall HTTP 요청을 공 하나당 하나씩 전송.
  다량 공이 연속 도착하면 수십~수백 fetch가 동시에 발생해 시작자 메인 화면과 팝업이 밀릴 수 있었음.
- finishBallQueue를 추가해 75ms마다 최대 80개를 finishBalls 한 요청으로 묶어서 서버 전송.
- 서버에 finishBalls batch action 추가. 배열 순서대로 순위를 기록하고 당첨판정 유지.
- 네트워크 요청 수를 크게 줄여 시작자 UI/팝업 반응성을 개선.

3) 기존 맵 이탈 방지와 기존 핀볼 물리는 유지.
