핀볼 1초 후 동시 시작 / 동일 화면 타임라인

기준:
- 사용자가 올린 '얌얌랜드 핀볼 최신판.zip' 그대로 기준.
- 화면배치/맵/물리엔진/참가자/당첨 로직은 수정하지 않음.
- app.js / server.js 동기화 부분만 수정.

동작:
1. 시작 버튼을 누르면 서버가 raceId, seed, startedAt을 먼저 확정.
2. 실제 물리는 서버시각 기준 약 0.82초 후 시작.
3. 모든 화면은 동일 snapshot을 약 0.18초 공통 버퍼로 재생.
4. 따라서 버튼 클릭 후 체감 약 1초 뒤에 시작한 사람/관전자 모두 같은 프레임부터 움직이기 시작.
5. 시작한 사람도 자기 로컬 물리를 바로 화면에 그리지 않고, 자신이 만든 공식 snapshot을 똑같은 0.18초 버퍼로 재생.
   → 시작자만 먼저 보이는 문제 제거.
6. 공 위치뿐 아니라 cam/camX/camZoom, 회전바, gate도 같은 snapshot 기준.
7. 각 브라우저는 1.5초마다 서버시각을 RTT midpoint 방식으로 보정.
   → PC 시계 차이/네트워크 왕복시간 때문에 시작 타이머가 어긋나는 문제 감소.
8. 단체/야미/꿀혜/선하/도릿 모두 room 값만 다르고 동일 코드 경로라 전부 적용.

현실적인 한계:
인터넷 지연이나 브라우저 프레임 스케줄링 때문에 수학적 0.000초 동일은 불가능하지만,
이번 구조는 '공식 시작시각 + 같은 공식 프레임 + 같은 공통 버퍼'를 사용해서 눈으로 봤을 때 같은 순간을 보도록 설계.
