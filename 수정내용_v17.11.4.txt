v17.11.4

1) 당첨기준 완전 동기화
- 숫자 선택/첫 번째/마지막을 '적용'하면 실제 server setWin 호출.
- 서버가 같은 방 모든 화면에 즉시 broadcast.
- 상단 '당첨: 22번째' 배지와 하단 현재 설정도 서버 값으로 갱신.
- 다른 사람 브라우저에 남아 있던 예전 localStorage/임시 설정이 서버 값을 덮어쓰지 않도록 수정.

2) 경기 초기화/설정 동기화
- 경기 초기화는 서버를 먼저 초기화하고 모든 화면이 동일 broadcast를 받아 로비로 전환.
- 다른 사람이 누른 초기화/설정 변경을 로컬 레이스가 다시 running 값으로 덮어쓰던 부분 제거.
- 새로고침도 현재 서버 상태를 다시 읽음.

3) 공 화면 동일화
- 독립적으로 각 PC에서 Box2D를 돌리는 방식은 미세하게 순서가 달라질 수 있어서 제거.
- 레이스를 누른 1개 화면이 공식 물리(host)를 실행.
- 다른 화면은 host의 WebSocket snapshot을 약 95ms 버퍼로 60fps 보간하여 그대로 표시.
- 따라서 내려가는 순서/속도/충돌/카메라가 같은 공식 화면을 보게 됨.
- snapshot 송신은 소량 공 약 31fps, 공이 많을수록 자동 완화. 오래된 프레임은 큐에 쌓지 않음.
- follower는 별도 물리를 계산하지 않아 CPU 부담도 줄어듦.

4) 현재 참가자
- 색 공 아이콘/숫자/닉네임 간격 분리.
- 입력자 이니셜 배지 추가: 야미=얌, 꿀혜=꿀, 선하=선, 도릿=도.
